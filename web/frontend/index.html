Conexión

Si la página se abre desde el backend (web/backend), se conecta sola al servidor, que ya escucha el broker y guarda el historial. Sin servidor, la conexión directa escucha <prefijo>/estado y <prefijo>/evento del STM32, y <prefijo>/est1 que publica el PC con ROS 2. El prefijo tiene que ser el mismo de stm32/inc/wifi_config.h. Es una página de solo lectura: no manda comandos al robot.
